# RGODBEAT Official PDF License Agreements

This directory is prepared to receive the official RGODBEAT Beat License Agreement PDF files.

When you finalize your legal PDF license agreements, you can place them here using any of the following filenames:

- `rgodbeat_mp3_license_agreement.pdf` (or `mp3.pdf`)
- `rgodbeat_wav_license_agreement.pdf` (or `wav.pdf`)
- `rgodbeat_unlimited_license_agreement.pdf` (or `unlimited.pdf`)
- `rgodbeat_exclusive_license_agreement.pdf` (or `exclusive.pdf`)

Alternatively, you can upload them directly to your Cloudflare R2 bucket under:
- `contracts/rgodbeat_mp3_license_agreement.pdf`
- `contracts/rgodbeat_wav_license_agreement.pdf`
- `contracts/rgodbeat_unlimited_license_agreement.pdf`
- `contracts/rgodbeat_exclusive_license_agreement.pdf`

The download system and customer portal (`/api/download/[purchaseId]?fileType=contract`) will automatically detect and deliver the official PDF files without requiring any code changes or rebuilding the checkout system.
